Artificial Intelligence (AI) refers to software that uses computational methods — including machine learning — to perform tasks that typically require human intelligence, such as pattern recognition, classification, or prediction. Machine Learning (ML) is a subset of AI in which a system learns from data to improve its performance without being explicitly programmed for each task.
A rule-based system follows explicitly programmed logic — such as fixed thresholds, decision trees, or clinical algorithms — rather than learning from data. It produces the same output for the same input every time, with no adaptation over time.

A PICO framework (Population, Intervention, Comparator, Outcome) is a structured tool used to define the research question underpinning a clinical study or HTA submission. Your PICO should reflect the intended population and use case described in your DHT's regulatory approval, and will be used to frame the scope of evidence generation activities and the evidence package submitted to HTA bodies.

What is the usual care or standard approach for this population?
If there is no established standard of care for this condition, your comparator should reflect either the clinical gold standard — that is, the care patients should ideally be receiving — or how the condition is currently managed in practice. This might include, for example, watchful waiting, periodic GP review, self-monitoring, or waiting list management. A clearly defined comparator is an essential component of a robust evidence generation plan and will be expected by HTA bodies when assessing your technology.
